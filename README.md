# منصة تقييم واختبارات الموظفين (Employee Assessment System)

نظام متكامل لإجراء اختبارات الموظفين (أسئلة اختيار من متعدد **MCQ** وأسئلة **صح أو خطأ True/False**) وحساب التقييمات آلياً مع **حجب النتيجة والدرجات تماماً عن الموظف** وعرضها فقط في **لوحة تحكم الإدارة (Admin Dashboard)**.

---

## 🛠 التقنيات المستخدمة (Tech Stack)

* **الباك إند (Backend):** ASP.NET Core 9.0 Web API (Minimal APIs).
* **قاعدة البيانات (Database):** SQLite عبر Entity Framework Core (تعمل تلقائياً بدون أي تثبيت إضافي).
* **الواجهة الأمامية (Frontend):** HTML5 + Tailwind CSS + Lucide Icons (تصميم عصري سريع ومتجاوب بالكامل باللغة العربية RTL، مدمج ومخدوم مباشرة عبر `wwwroot` بدون الحاجة لتثبيت Node.js أو حزم إضافية).

---

## 🚀 كيفية تشغيل المشروع

المشروع جاهز ومُشغل حالياً. إذا رغبت في إعادة تشغيله في أي وقت:

1. افتح موجه الأوامر (Terminal / PowerShell) في مجلد المشروع:
   ```powershell
   cd C:\Users\LENOVO\.gemini\antigravity\scratch\EmployeeAssessment
   ```

2. نفّذ الأمر التالي:
   ```powershell
   dotnet run
   ```

3. افتح المتصفح على الروابط التالية:
   * **بوابة الموظف للاختبار:** [http://localhost:5000](http://localhost:5000)
   * **لوحة تحكم الإدارة والنتائج:** [http://localhost:5000/admin.html](http://localhost:5000/admin.html)

## 🔒 معايير الأمان والخصوصية (Key Privacy Feature)

* **منع تسريب الإجابات في الفرونت إند:** عند جلب بيانات الاختبار للموظف (`GET /api/tests/{id}`)، يقوم السيرفر بحذف حقل `isCorrect` تماماً من الـ JSON، فلا يمكن استخراجه من أدوات فحص المتصفح (Inspect Element).
* **حجب التقييم والدرجة عن الموظف:** عند تسليم الاختبار (`POST /api/tests/{id}/submit`)، يتم حساب الدرجات وتخزينها في قاعدة البيانات فوراً، ويُرجع السيرفر رسالة تأكيد فقط:
  > *"تم تسليم الاختبار بنجاح. تم حفظ إجاباتك وإرسالها للإدارة للتقييم."*
* **التقييم الكامل في لوحة الإدارة:** يظهر للأدمن في لوحة التحكم:
  * درجة كل موظف (مثلاً: `40 / 50`) والنسبة المئوية وحالة الاجتياز (`Passed / Failed`).
  * تفاصيل كل سؤال: ما اختاره الموظف مقابل الإجابة الصحيحة المعتمدة.
